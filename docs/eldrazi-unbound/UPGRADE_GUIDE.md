# Eldrazi Unbound Precon Upgrade Plan: Bracket 1/2 → Bracket 3

## Current Deck Status
- **Commander**: Kozilek, the Great Distortion (or Zhulodok, Void Gorger as face commander)
- **Current Bracket**: 1-2 (standard for precons)
- **Goal**: Upgrade to Bracket 3 (Upgraded)

## Bracket 3 Rules
- **Up to 3 Game Changers** allowed (prohibited in Brackets 1-2)
- **No mass land denial**
- **No early two-card combos** (games should last at least 6 turns)
- Well-tuned decks with stronger cards and synergies

---

## Quick Summary

| Version | Cost | Game Changers | Titans | Key Difference |

| **Full Upgrade** | $180-250 | 3 | 3 | Maximum power, faster with Mana Vault |

## Version Comparison

| Aspect | Full Upgrade | Mid-Range |
|--------|--------------|-----------|
| **Cost** | $180-250 | $80-120 |
| **Game Changers** | 3 (maximum for B3) | 2 |
| **Eldrazi Titans** | 3 | 2 |
| **Speed** | Faster (Mana Vault) | Slightly slower |
| **Consistency** | High | High |
| **Missing Cards** | None | Mana Vault, Ulamog Infinite Gyre |
| **Extra Synergy** | Less copy effects | Lithoform + Strionic doubling |

**Recommendation**:
- If you want maximum power and play frequently: **Full Upgrade**
- If you want great value and like combo-style plays: **Mid-Range**
