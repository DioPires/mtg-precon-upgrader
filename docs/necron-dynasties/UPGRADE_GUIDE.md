## Strategy Overview

**Imotekh the Stormlord** rewards you for artifacts leaving your graveyard by creating 2/2 Necron Warrior tokens. The key to maximizing this deck is:

1. **Fill your graveyard** with artifact creatures
2. **Recur them** to trigger Imotekh
3. **Sacrifice outlets** to repeat the cycle
4. **Combo finishes** using Nim Deathmantle + Altar combinations

## Key Infinite Combos (All 3+ Pieces)

All combos require setup and don't win before turn 6, keeping you in Bracket 3.

### 1. Ashnod's Altar + Nim Deathmantle + Wurmcoil Engine
- Sac Wurmcoil to Altar (2 mana) + get 2 tokens
- Pay 4 to return Wurmcoil with Deathmantle
- Sac both tokens (4 mana)
- **Result**: Infinite colorless mana, infinite tokens, infinite lifegain

### 2. Ashnod's Altar + Nim Deathmantle + Grave Titan
- Sac Titan (2 mana) + get 2 zombies
- Pay 4 to return Titan, get 2 more zombies
- Sac zombies for mana, repeat
- **Result**: Infinite zombies, infinite mana

### 3. Phyrexian Altar + Tortured Existence + Imotekh
- Sac a Necron token for B
- Pay B to swap creature from grave to hand (triggers Imotekh = 2 tokens)
- Net: +1 token per cycle
- **Result**: Infinite tokens, infinite ETB/LTB triggers

### 4. Ashnod's Altar + Nim Deathmantle + Marionette Master
- With 4+ artifacts, each artifact death drains opponents
- **Result**: Infinite damage (win condition)

### Existing Combos (Already in Precon)
- Trazyn + Staff of Domination + Sol Ring/Sceptre = Infinite mana/draw
- Illuminor Szeras + Nim Deathmantle + Dross Scorpion = Infinite mana
