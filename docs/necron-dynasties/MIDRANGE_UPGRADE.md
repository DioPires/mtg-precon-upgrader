## Key Synergies

### Infinite Combo #1: Wurmcoil Engine Loop
**Cards**: Ashnod's Altar + Nim Deathmantle + Wurmcoil Engine

1. Sacrifice Wurmcoil Engine to Ashnod's Altar (get 2 mana)
2. Wurmcoil dies, creates 2 tokens (Lifelink + Deathtouch)
3. Deathmantle trigger - pay 4 to return Wurmcoil
4. Sacrifice both tokens (get 4 mana)
5. Repeat

**Result**: Infinite colorless mana, infinite 3/3 tokens, infinite lifegain

### Infinite Combo #2: Phyrexian Altar + Tortured Existence
**Cards**: Phyrexian Altar + Tortured Existence + Imotekh (commander)

1. Have a Necron token and 2+ creatures in graveyard
2. Sacrifice token to Phyrexian Altar for B
3. Activate Tortured Existence (pay B, discard creature, return creature from grave)
4. Artifact creature left graveyard = Imotekh triggers = 2 new tokens
5. Repeat (net +1 token per cycle)

**Result**: Infinite tokens, infinite ETB/LTB triggers

### Infinite Combo #3: Marionette Master Kill
**Cards**: Ashnod's Altar + Nim Deathmantle + Marionette Master

1. Have Marionette Master with 4+ power (Fabricate counters)
2. Each time an artifact dies, opponents lose life equal to Master's power
3. Loop any artifact creature with Altar + Deathmantle
4. Each death = 4+ damage to each opponent

**Result**: Infinite damage to all opponents
