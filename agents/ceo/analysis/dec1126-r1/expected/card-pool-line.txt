- **Card pool**: All Commander-legal cards printed up to and including the current date of the analysis. There is no frozen cutoff — treat "the day this deck is being designed or reviewed" as the boundary. When in doubt about a recent printing, query Scryfall rather than assuming a stale window. A session that has the card tools uses `scryfall_search` (with `released<=YYYY-MM-DD` if needed). An agent run has no card tools: it runs `uv run python scripts/card_lookup.py --search "QUERY"` (from eternities-mtg-app, by its absolute path `/Users/dpires/Documents/Personal/code/mtg-precon-upgrader/scripts/card_lookup.py`). QUERY takes Scryfall's search syntax, `released<=YYYY-MM-DD` included. Put single quotes around a QUERY that holds a double quote. Nobody sends `curl`, or any request outside `scripts/scryfall_api.py`, to `api.scryfall.com`.
