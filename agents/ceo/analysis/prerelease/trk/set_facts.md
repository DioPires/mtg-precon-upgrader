## Collector-number gaps

The main numbering runs #1 to #306; 0 numbers in that range are missing, and 5 cards are numbered above it.

A gap is almost always a showcase-first printing: `unique=cards` keeps one printing per card, and when the special-treatment version is the one it keeps, the main-set number looks absent while the card sits above the main numbering. The prints dump resolves each gap below. Treat a gap with no printing at all as a real hole and re-dump.
