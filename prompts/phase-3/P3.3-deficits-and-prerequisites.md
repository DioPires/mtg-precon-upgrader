**Requirements:** DB-4, PR-1, PR-3, PR-5, IN-4, TX-3, UC3.

drives Tier-B near-misses and the UC3 failure explanation in user terms (TX-3).

optimisation (min over action orderings of the worst-case running deficit) + the
guard set (zone/timing/control/summoning-sickness + command-zone, IN-4; CR 903.3d).
State the model-conditional caveat (PR-5).
