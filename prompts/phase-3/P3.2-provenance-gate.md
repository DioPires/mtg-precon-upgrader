# P3.2 — Provenance gate + corroboration/novel split

**Requirements:** DB-6, DB-7, EI-2, EI-4, QE-4.

Enforce the plan-6b provenance gate: a Tier-B verdict consumes only
deterministic/human-reviewed items (`combo_kb_lib.tier_b_view`). A loop that would
close using a dropped LLM/community item is capped at Tier C with an explicit
reason (dual gated/ungated path). Split corroboration (curated loop → Tier A, DB-7,
cannot inflate) from novel (not-in-corpus verified loop, stricter gate). Add the
`CLOSE_SAFE` backstop: only templates whose closure is derivable from the coarse
features may assert closure — the primary QE-4 guard.
