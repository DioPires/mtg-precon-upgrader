# P3.1 — Closure model + deterministic verifier

**Requirements:** DB-1, DB-2, DB-3, DB-5, DB-6, NF-3.

Implement the deterministic Tier-B loop verifier in `scripts/combo_verifier_lib.py`.
Model each member (2-3 cycle pieces + ambients, DB-3) from its Tier-B KB view:
mana produced, priced costs, events emitted, triggers, guards, feature roles.
Decide closure by PRD 6.5 (piece recurrence, resource solvency, strict gain,
finite-zone soundness) and classify by the pair (k, finite-zone bound) — infinite
(k=0) / value engine (k>0), the bound an attribute on either class. Verification is
deterministic (DB-5, no generative call). Record the provenance chain verdict →
entry versions → extraction path (DB-6). Latency is precompute-time (NF-3).

Deliverables: `scripts/combo_verifier_lib.py`, `docs/combo-verifier.md`.
