# P2.3 — Ranking v1 (reduced-signal) + coarse bands

**Requirements:** RK-1, RK-2 (partial — completed Phase 3), RK-5, RK-6, DC-4

## Objective
Rank Tier-C candidates by a reduced-signal score and present coarse speculative
bands only. Phase-2 ranking is provisional and unvalidated against RK-3 until the
Phase-3 calibration.

## Signals (reduced set — plan decision 4)
- **Magnitude** (KB-2): scalar feature magnitudes on the matched edges.
- **Deck fit** (RK-2): alignment of the candidate's feature profile with the
  decklist's aggregate feature histogram (a mill payoff ranks higher in a mill
  deck).
- **Crowd prior** (RK-2): EDHREC co-occurrence — **fleet mode only** (decision 4).
  Paste mode omits the term and the ranking explanation says so.
- Mechanistic rate + startup cost are **dark** until Phase 3 (need the verifier's
  vectors); they join with a re-fit then.

## Acceptance
- RK-5: presentation is tiered + coarse bands (`strong` / `speculative`), never a
  falsely-precise scalar.
- RK-6: ranking never alters tier — a low-ranked Tier-C signal stays speculative.
- DC-4: unranked raw edge dumps are not the default presentation.
