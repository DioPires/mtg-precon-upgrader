# P2.5 — Web Tier-C surface + deep-scan

**Requirements:** DC-4, TX-1, TX-2, EI-1, EI-4, RK-5, RK-6

## Objective
Surface Tier-C synergies in the Combo Lab route. Fleet mode renders the
precomputed `synergy-candidates.json`; paste mode runs the client engine mirror.

## Deliverables
- `web/src/data/synergy.ts` — types + loaders: compact feature-index in-memory
  loader (bypasses localStorage like the matcher index), `synergyCandidates`
  bundle member wired into `deckLoader`, `STORAGE_PREFIX` bump.
- `web/src/lib/synergyMatch.ts` — paste-mode engine mirror of
  `combo_synergy_lib.py` (magnitude + deck-fit; NO crowd prior). Comment:
  keep in sync; guarded by a parity test.
- `web/src/routes/ComboLab.tsx` — Tier-C section under the Tier-A findings
  (RT-2 order). Triples + 4-cycles behind a **deep-scan** action (OQ-3); pairs by
  default.

## Acceptance
- Every finding shows a Tier-C badge (EI-1); "heuristic / speculative" language,
  never verified-combo language (EI-4). Tier is legible at a glance (TX-2).
- Each synergy explains its matched edges with magnitudes (DC-3 / TX-1 Tier-C).
- Coarse bands only (RK-5); ranking never alters tier (RK-6).
- Paste-mode ranking note states the crowd prior is omitted (decision 4).
