# P2.7 — QE-1a regression + parity + unit tests

**Requirements:** QE-1 (a-slice)

## Objective
Prove the C-layer proposes known combos as candidates (QE-1a), and that the
Python engine and its TS paste-mode mirror agree on the no-prior core.

## Deliverables
- `scripts/qe1a_synergy_regression.py` — samples curated 2-card combos from
  `data/spellbook/matcher-index.json`, builds a synthetic deck of the two cards,
  runs the C-layer, asserts the pair is proposed. Reports **recall** and lists
  misses as ontology-gap diagnostics (QE-2: a C-layer miss localizes a gap).
- `tests/test_combo_synergy.py` — engine unit tests (graph, enumeration, ranking
  invariants RK-5/RK-6, uncovered handling) + a Python↔TS parity fixture.
- `web/src/lib/synergyMatch.test.ts` — vitest for the TS mirror; parity against
  the committed fixture.

## Acceptance
- QE-1a is a committed, runnable script/test; recall reported (not required at
  100% — misses are diagnostics per QE-2).
- Parity: identical deck → identical pair candidate set across Python and TS
  (no-prior core).
