# P4.5 — UI wiring + filters + deck-URL field + latency (NM-5 / NF-4 / OQ-1)

**Requirements:** NM-5, IN-2, NF-4, OQ-1, EI-1/EI-2/EI-4.

`web/src/routes/ComboLab.tsx`:
- **CompletionPanel** — on-demand ("Find completions") lazy-loads the feature index + price index +
  synergy config and runs `analyzeCompletions` for both fleet (with precomputed engine deficits) and
  paste (Tier-C only; Tier-B deferral disclosed). Renders Tier-B + Tier-C completions with tier badges,
  coupling explanations (DC-3), prices, and the "verified under the model" qualifier (EI-2).
- **Filters (NM-5)** — currency (EUR/USD), max price, and an optional owned-collection paste (OQ-1,
  stays in the browser; `priv_data/` never deploys). Filter changes recompute in-memory (no refetch).
- **Latency line (NF-4)** — reports pool size + elapsed ms + per-filter drop counts.
- **Deck-URL field (IN-2)** — Moxfield/Archidekt URL → paste fields via `resolveDeckUrl`, with the
  degradation message inline.
- **Export (RT-4)** — Copy text / Copy Markdown / .txt / .md, all including the computed completions.

Styling via global `gv1-*` classes + `styles/combo-lab.css` additions (no Tailwind/CSS-in-JS).
Real-browser verification: `web/tests/combo-lab.spec.ts` (chromium) covers the completion panel, the
paste Tier-B deferral, the deck-URL degradation, and Markdown tier-label survival.
