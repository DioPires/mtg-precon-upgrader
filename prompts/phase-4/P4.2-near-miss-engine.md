# P4.2 — Computed near-miss completion engine (NM-1..NM-7)

**Requirements:** NM-1..NM-7, NF-4.

`web/src/lib/nearMissComplete.ts` — the mechanistic recommendation engine (NM-7). Given a decklist,
find pool cards that CLOSE the deck's near-misses, in two computed tiers mirroring the epistemic
structure (NM-1):

- **Tier C (speculative)** — dangling half-edges in the deck's provides/wants graph (a deck feature F
  whose compatible partner G nothing in the deck carries), paired with pool cards that carry G. Uses
  the SAME collapsed feature model + compat relation as `synergyMatch.ts`, so adding the card forms the
  coupling the Tier-C synergy engine would then display (consistency by construction).
- **Tier B (computed)** — a candidate loop failing closure by a concrete numeric deficit (from the
  Phase-3 verifier's precomputed deficit vectors, fleet only), paired with pool cards whose per-iteration
  contribution closes the leak. NM-2 is honoured upstream (the deficit IS the verifier's event-trace-aware
  output); the closer map admits only per-iteration amplifiers/reducers (`trigger_doubler`,
  `cost_reduction`), NOT one-shot `mana_add` (which would inflate the tier past the model). Ambient
  modifiers are first-class closers (NM-3). Paste-mode Tier-B is deferred with the verifier mirror.

Search runs CLIENT-SIDE over the committed full-coverage KB feature index (the deployed KB projection):
per-hole cost linear in pool size, pure precomputed-vector matching, no generative calls and no
"add each card and re-analyze" brute force (NM-4). Measured ~58 ms over 31,830 cards (NF-4 budget).

**Distance-to-closure (6.6)** — `distanceToClosure(missingPieces, deficitMagnitude)`; monotone in both,
piece-count dominates, so "missing 1 generic mana" (a pure numeric deficit, distance < 1) ranks CLOSER
than "missing a whole engine piece" (distance 1), exactly the 6.6 worked example. Near-misses ranked by
distance then the completed-finding strength (NM-6).

**Filters (NM-5)** — color identity (completer ci ⊆ deck ci), format legality (the KB pool is
Commander-legal by construction), price (EUR/USD selectable, max cap; unpriced cards pass), and — via
`parseOwnedCollection` — an owned-collection restriction (OQ-1, optional). Each filter's drop count is
reported for honest disclosure. Near-miss stays a REPORT: nothing edits or hosts a deck (NG5).
