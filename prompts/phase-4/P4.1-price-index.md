# P4.1 — Price data derivative (DR-5)

**Requirements:** DR-5 (price data, EUR Cardmarket + USD, freshness ~days), NM-5 (price filter substrate).

The Scryfall oracle mirror drops prices, so `scripts/build_price_index.py` fetches the Scryfall
bulk `oracle_cards` export fresh (it carries per-card `prices`), filters to Commander-legal, and
emits a compact committed derivative under `data/spellbook/`:

- `price-index.json` — normalized name-key → `[eur, usd]` (non-foil; eur=Cardmarket, usd=TCGplayer;
  `null` when unpriced; `//`-faces aliased first-wins). Compact, `sort_keys` for a delta-friendly
  weekly git diff. ~1 MB, 32,157 keys.
- `price-index.meta.json` — provenance + freshness (DR-7).

All generation is LOCAL; the JSON deploys via the Vercel `cp -R ../data` step (no build-time Python).
`web/src/data/prices.ts` loads it in-memory with a freshness `?v=` buster, BYPASSING the localStorage
envelope (same posture as the matcher/feature indexes). The runtime never calls a price API (NF-1).

Keys fold with the exact `normalize_name()` the matcher/synergy engines use, so a completer card
resolves by the same name-key the feature index names it by.
