# P1.4 — Offline LLM classifier harness (injection-hardened)

**Requirements:** KB-5, IN-7, NF-1, QE-3

## Objective
Fill fields deterministic extraction could not derive, for `needs_llm` cards.
Per-card, batch, offline — never on the query path. IN-7 residual: card text is
data, never instructions.

## Deliverables
- `scripts/classify_combo_kb.py` — `--emit-batch` (hardened prompts) / `--apply` (merge)

## Acceptance
- Oracle text sanitised of forged fences + role prefixes, wrapped in a fenced
  data block; system instruction forbids obeying in-data directives.
- Closed feature vocabulary; out-of-vocab → `ontology-gaps.json` (QE-3), never invented.
- Outputs stamped `llm` (not Tier-B eligible until human-reviewed). Tested in P1.3.
