# P1.2 — Deterministic extraction + provenance gate

**Requirements:** KB-1, KB-2, KB-4, DR-1, DR-2

## Objective
Extract every KB field mechanically derivable from oracle text / type line /
mana cost via the local Scryfall mirror (DR-1), maximising deterministic
coverage before any LLM pass. Encode per-field + per-item provenance (KB-4) and
the enforced Tier-B gate.

## Deliverables
- `scripts/combo_kb_lib.py` — provenance vocabulary + `tier_b_view` gate
- `scripts/build_combo_kb.py` — extractor → `data/combo-kb/entries/*.json` + `meta.json`

## Acceptance
- Provides/wants/ambient with magnitudes; events, triggers, costs, guards.
- DFC faces both extracted (IN-5). All items stamped `deterministic`.
- Tier-B gate = {deterministic, human-reviewed}; llm/community-tag excluded.
- Committed JSON: sort_keys, indent 2; full pool under the ~150 MB gate.
