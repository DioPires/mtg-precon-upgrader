# P1.1 — Ontology v1

**Requirements:** KB-1, KB-2, KB-3, QE-3, RSK-3

## Objective
Author the versioned provides/wants ontology + resource/event/guard type system
the whole KB is expressed in. Seed from the 15-role taxonomy
(`docs/role-taxonomy.md`) and the KB-3 mandated trigger economies.

## Deliverables
- `scripts/gen_combo_kb_ontology.py` — generator (regex as readable raw strings)
- `data/combo-kb/ontology.json` — v1.0.0 artifact loaded by extractor + classifier

## Acceptance
- Every KB-3 economy representable (ETB, dies, LTB, cast, sacrifice outlet+fodder,
  blink, untap, tap-ability, token, mill, drain/lifegain, cost reduction, trigger
  doubling, recursion).
- Scalar magnitude extraction where the effect is quantitative (KB-2).
- Versioned with changelog; each regex compiles (tested in P1.3).
