# P1.7 Stage-2 Wave 1 — QA evidence (fleet `needs_llm`)

**Requirements:** KB-5, KB-7, QE-5 · **Wave:** 1 (fleet decklist `needs_llm` cards)
**Classifier:** `llm-classifier-v1` · **Ontology:** v1.0.1 · **Corpus:** 2026-08-15

## Scope
191 cards — every card that is (a) in a fleet decklist and (b) flagged
`needs_llm` after the deterministic pass. Highest Tier-B value: these feed real
combo verdicts first. Targeted via the new `classify_combo_kb.py --names-file`
enabler (oracle_id list).

## Method
`--emit-batch --names-file` produced 191 hardened per-card prompts (IN-7:
oracle text fenced as untrusted data, closed feature vocabulary). The prompts
were run through the offline batch classifier (build-time only, KB-5/NF-1 — never
the query path) and `--apply`-ed. Outputs stamped `llm` → **not Tier-B eligible**
until human review (`combo_kb_lib.TIER_B_PROVENANCES`).

## Results

### Coverage / convergence
- `needs_llm`: 6,701 → **6,510** (−191). `llm_classified_count` = 191.
- `check_kb_coverage.py --stage full`: **PASS** (33,462/33,462).
- Provenance histogram: `deterministic` 86,417 · `llm` 77 (gate unchanged: llm
  items add no Tier-B-eligible signal).

### Vocabulary integrity (automatic, closed-vocab gate)
- **0 / 77** out-of-vocabulary feature ids (all invented ids would be dropped +
  logged; none occurred).
- **0** mis-bucketed items (every feature landed in its ontology `kind` bucket).
- **179** ontology-gap notes logged for QE-3 (see below).

### Classification correctness (KB-7 elevated review — all 77 feature items)
All 77 assigned features were reviewed against oracle text (implementer review;
FE provides the independent sign-off gate):
- **77/77 defensible; 0 outright wrong.**
- 5 flagged *generous* (kept, llm-tier / Tier-C capped, noted for FE):
  lifelink-grant→`lifegain` (Scales of Shale, Syphon Sliver), poison→`counter_add`
  (Vraska's Fall), counter-amplifier→`counter_payoff` (Hardened Scales),
  tutor-to-graveyard→`self_mill` (Buried Alive).
- 127/191 cards correctly classified **empty** — pure removal / counterspell /
  tutor / ramp / protection / board wipe, none of which are combo-economy
  features by ontology design. These are now `needs_llm=false` (processed), not
  re-queued.

### Evidence grounding (llm `evidence` field)
- 32/77 (41.6%) of llm `evidence` strings are verbatim oracle substrings; the
  rest are faithful paraphrases (reordered Triome color pips, `…`-joined cycling
  spans). By design the auto-QA grounding check scopes to deterministic items,
  because llm `evidence` is model rationale, not a verbatim snippet.
- **Follow-up (wave 2):** tighten the classifier prompt to prefer verbatim
  ≤80-char oracle snippets so llm evidence grounds at deterministic parity.

## QE-3 ontology-gap candidates surfaced (for ontology-drift review)
Genuine mechanics not yet in the vocabulary (vs. intentional out-of-scope
removal/tutor/counterspell noise): **counter doubler** (Hardened Scales,
Branching Evolution), **damage doubler** (Twinflame Tyrant), **life-loss
doubler** (Bloodletter of Aclazotz). Recommend evaluating a `counter_doubler` /
`damage_doubler` ambient feature in a future ontology bump (v1.1).
