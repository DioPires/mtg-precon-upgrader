## Scope
200 cards — the top 200 still-`needs_llm` cards ranked by **Commander Spellbook
variant-membership count** computed from the local corpus
(`data/spellbook/matcher-index.json`: count of `variants[].u` memberships per
card). These are the highest Tier-B combo value after the fleet: every one is a
real combo participant. Membership range **28 … 1236** (Ashaya, Falco Spara,
Freed from the Real, Mycosynth Lattice, Arcane Adaptation …).

Targeted via `classify_combo_kb.py --emit-batch --names-file` (oracle_id list).
Remaining Spellbook-participating `needs_llm` after this wave: **648** (Waves 3+
continue down the same ranking, then the non-combo long tail).

## Method
`--emit-batch --names-file` produced 200 hardened per-card prompts (IN-7: oracle
text fenced as untrusted data, closed feature vocabulary). Classified offline
(build-time only, KB-5/NF-1 — never the query path) against the v1.0.1 closed
ontology; `--apply`-ed. Outputs stamped `llm` → **not Tier-B eligible** until
human review (`combo_kb_lib.TIER_B_PROVENANCES`).

**Evidence grounding (Wave-1 FE follow-up closed):** every feature item's
`evidence` string was authored as a **verbatim ≤80-char oracle substring** and
machine-checked against the fenced oracle text — **44/44 (100%)** verbatim, up
from Wave 1's 41.6%. This lands the parity the FE requested for Wave 2.
