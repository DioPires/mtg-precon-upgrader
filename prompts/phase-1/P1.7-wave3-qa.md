# P1.7 Stage-2 Wave 3 — QA evidence

**Wave 3 = the remaining 348 Spellbook-participating `needs_llm` cards** (variant-membership
rank 501…end, membership 4…1). Completing this wave drains the **entire**
Spellbook-participating `needs_llm` set to **zero** — every card that appears in any
Commander Spellbook variant is now classified (deterministic ∪ llm). What remains
`needs_llm` (5,662) is the non-combo long tail: cards that participate in no Spellbook
combo, deferred to bulk long-tail waves before the `phase1-full-acceptance` gate.

## Method
- **Selection:** ranked still-`needs_llm` cards by Commander Spellbook variant-membership
  (`data/spellbook/matcher-index.json` `variants[].u` counts), took every card with
  membership ≥ 1 not yet classified = 348. Verified post-apply that 0 Spellbook-participating
  `needs_llm` remain.
- **Classifier:** offline build-time batch (KB-5/NF-1 — never on the query path). Emitted
  348 IN-7-hardened prompts via `classify_combo_kb.py --emit-batch --names-file` (fenced,
  untrusted oracle data), split into 7 slices, classified by 7 parallel build-time
  classifier operators against the closed v1.0.1 ontology, then `--apply`.
- **Provenance:** every output stamped `llm` → Tier-C capped, **never** Tier-B-eligible until
  human review (`TIER_B_PROVENANCES = {deterministic, human-reviewed}`).
